About

I'm a solo maker in Japan. I build browser games and 3D-printed mechanisms with the help of AI tools, and I write honest notes about what worked, what failed, and which tools were actually worth it.

My main project is an evolution game series where players design a creature's body and a neural network + genetic algorithm learns how to move it. I also design gear mechanisms — like a spring-driven wind-up car — and print them on a Bambu Lab A1.

What I test and write about

  • AI tools for solo developers and makers
  • Tools for publishing small games and sites
  • Video and design tools for sharing the build process

I only write about tools I have tried myself. If a post contains an affiliate link, that is stated on the page — see the disclosure.
